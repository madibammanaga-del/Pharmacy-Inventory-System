# Pharmacy-Inventory-System
HealthFirst PIMS is a Java-based Pharmacy Inventory Management System developed using Java Swing and MySQL. The system is designed to help pharmacy staff manage medicines, suppliers, users, sales, stock levels, and reports through a user-friendly graphical interface.

# Features
User Authentication
Secure user login
User roles and access management
Welcome message for logged-in users
Logout functionality
Medicine Management
Add and manage medicines
View medicine information
Manage stock quantities
Track reorder levels
Monitor medicine expiry dates
Supplier Management
Add and manage suppliers
View supplier information
Update supplier records
Sales and Point of Sale
Cashier Point of Sale (POS)
Select medicines for sale
Calculate sales totals
Process checkout
Generate a full sales bill
Record sales in the database
View sales history
Reports
